# Task examples

`example-task` in this folder is the reference for what a finished task in this
repository looks like.

A task counts as implemented when **both** of the following hold:

1. `docs/task.md` is present, is not empty, and contains ASCII characters only
   (English text; no Chinese or other non-ASCII characters).
2. `evaluation/main.py` is present.

Apart from the content requirements spelled out above, only the existence of
the required files needs to be checked. No other files are required, and extra
files never hurt.
